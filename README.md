# Умник AI

Мульти-модельный AI-помощник. Стартовый проект на Next.js и TypeScript.

## Возможности стартовой версии

- Интерфейс чата
- Серверный API-маршрут для Gemini
- Настройки провайдеров через переменные окружения

## Запуск

1. Установите Node.js 20 или новее.
2. Выполните `npm install`.
3. Скопируйте `.env.example` в `.env.local` и добавьте `GEMINI_API_KEY`.
4. Выполните `npm run dev`.

Интеграции OAuth, почта, генерация изображений/видео и остальные AI-провайдеры пока не реализованы — их нужно подключать отдельно с соответствующими API-ключами и настройками безопасности.
